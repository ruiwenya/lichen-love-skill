# 跨 AI 兼容说明

## 使用普通文件，不依赖某个产品

主要资料都是中文 Markdown。支持 Skill 的环境可读取整个文件夹；不支持时，可把入口和相关资料作为附件或知识库。不同产品是否自动加载、怎样上传，以它实际提供的功能为准。

不要要求所有终端都能访问原作者机器上的目录。先确认当前能看到哪些文件。

## 没有本地 HTML

先读 `SKILL.md` 和 [说话方式与示例](输出模板与案例.md)，再按问题选择一份相关资料。需要整套观念时读 [中国式心理与情感体系](中国式心理与情感体系.md)。

专题摘要已经能支持主要分析，但它不是全文。不要说“我看了截图”，也不要引用摘要里没有的逐字原话。需要原文的细节，可以请用户提供对应文章或图片，不必因此拒绝回答已经能解释的部分。

## 有本地 HTML

在文章库根目录运行：

```bash
python3 Lichen-LOVE-skill/scripts/search_articles.py --root . --keyword "分析人" --keyword "父母" --limit 20
```

搜索结果用于定位，之后要打开文章。脚本只搜文件名和 HTML 可提取文字，不识别图片中文字。图片和长图直接用当前 AI 的识图功能读，不安装 OCR 库。工具看不到图，要说明哪些没读到。

有本地快照时可加 `--include-skill`；没有快照不要把目录说明当成已有原文。

原文与摘要不一致，以读到的原文为准。更新文章摘要，不顺便公开 HTML 和截图。

## 简短启动提示

```text
请按 lichen-love-skill 分析。先读 SKILL.md 和 references/输出模板与案例.md，再选与问题有关的资料。用自然、具体的中文，说明这个人想要什么、为什么这样做，以及家庭有什么影响。缺少关键信息再问，不发问卷，不固定给话术或退出建议。分清李晨的观点、原文事实和你自己的解释。
```

想练习分析时：

```text
请用这个 Skill 带我分析一次。先让我指出最奇怪的地方，再一起想这个行为给当事人什么好处，是否反复发生，家庭怎样影响了他。每次问最关键的，已经能说明白时就直接说结论，不要永远提问。
```

分享快乐或日常感受时：

```text
请用这个 Skill 看看我描述的感受。先说具体哪里有意思、和以前有什么不同，不必找心理问题。日常活动、食物、运动、聊天、艺术都只是例子，请结合我真正喜欢和经历过的事情。
```

有本地文章时：

```text
本地有文章 HTML。请先检索，打开正文，并直接阅读其中图片。没有看见的部分请说明，不用 OCR，也不要把摘要说成全文。
```

## 保持一致的几点

三大法宝是吃喝玩乐、分析人、广泛深入大量正常快乐的异性交往，出处是《幸福是斗出来的！》的手写图。集体活动只是第三项的一种途径，不能用它替代第三项。五项能力是欲望、感知力、暧昧能力、激情能力、为人处事能力。

关于转变的三个要点，另见 [幸福是斗出来的](文章资料库/幸福是斗出来的.md)：自私是最大的力量源泉、活该是最好的心理疗愈、理论是最强的行动指导。要读相应含义，不把标题直接当成对用户的训话。

“特异性心理需求”要用具体行为解释；“主体性”要说清这个人想要什么、怎样自己决定；“享受”不限定某种爱好或消费。

可以直接判断，也要愿意根据新材料改。不能因为想更像人，就故作粗鲁、油腻或亲密。全文语言示例以 [说话方式与示例](输出模板与案例.md) 为准。

只用文章案例或标明虚构的例子，不加入用户私人经历。分析尖锐问题不自动说教，但不提供欺骗、胁迫、侵犯同意和利用创伤控制人的办法。
