# 李晨常用的情感词语

## 为什么整理这些词

直接、具体不等于只写干巴巴的动作。李晨的文章经常使用有身体感觉、有生活气息的词，例如“荡漾、激情、甜蜜、娇羞、欢愉、酣畅淋漓”。这些词能让读者知道一种快乐到底是什么滋味。

问题不在感情词多，而在词语后面没有事情。写“她听完笑了，低头捂了一下脸，过一会儿又抬头逗他”，再说“笑得有些娇羞”，读者知道你看见了什么。只写“关系被接住，双方都活了”，读者仍然不知道发生了什么。

下面的用法依据本地历史文章整理，不是要求每次回答都使用。

文章库里既有李晨自己的正文，也有他选发的学生体会、对话和引用材料。这里记录的是他反复使用、认可或拿来分析人的表达，不声称每个词都是他创造的。统计只能帮助寻找文章，最终仍以具体上下文为准。

李晨会把它用于细雨落在头发和脸上的爱抚感，也会写亲吻以后心里躁动，甚至写一道意面“荡漾般的好吃”。它有轻柔、飘忽、身体舒服又有些心动的感觉。

### 舒爽、惬意、迷离、回味

这些词常用于天气、食物、阳光、风、旅行和艺术感受。

- **舒爽**：身体舒展开，呼吸和口感都顺畅。例如细雨、筋道的面、热闹的早饭。
- **惬意**：人在一个环境里待得舒服，不急着离开。例如午后阳光、山顶啤酒、落日散步。
- **迷离**：光线、风、酒、食物或情绪让人有些恍惚，又舍不得马上结束。
- **回味**：事情结束以后还会想起其中的味道、画面或身体感觉。

## 欲望刚出现的时候

### 心动、悸动、躁动

- **心动**：眼前出现了一个具体的人，注意力被他吸引，想靠近又可能紧张。不能因为觉得对方条件好就叫心动。
- **悸动**：比“喜欢”更轻、更细，常伴着忍不住笑、心跳变化和青春感。它可以发生在一句微信、一次对视或一段男女互动里。
- **躁动**：不是单纯焦虑，而是喜欢异性、想寻找和接近异性的本能力量已经起来了。李晨把“躁动感”看作恋爱基础的一部分，重点是这种力量会不会变成寻找、接近和表达。

### 惦记、牵挂、想念、思念

这些词都表示对方不在眼前时，心里仍有他，但轻重不同。

- **惦记**很生活化：记得他要做什么，看到东西想起他，愿意顺手给他留一份。
- **牵挂**多了一点责任和不放心，会关心他现在过得怎样。
- **想念、思念**更直接地写分别后的情感和身体感受。说自己想念并不等于感情深，要看他是否真想见、是否为见面腾出时间。

## 两个人之间的情感

### 娇羞、甜蜜

- **娇羞**不能只靠一个笑容判断。李晨常注意掩面、偷笑、脸红、想看又躲开等一组动作。
- **甜蜜**不是关系身份，而是两个人互相喜欢、调情、亲近时的基本感受。写谁在逗谁、谁主动靠近、分别以后还惦记什么，会比单独说“很甜”清楚。

### 浓情蜜意、难舍难分、情不自禁

这些词适合双方已经明显互相喜欢、身体也愿意靠近的场面。

- **浓情蜜意**：不是礼貌客气，而是彼此注意力都在对方身上。
- **难舍难分**：已经到了分别的时候，两个人仍想多待一会儿，或者很快又想见面。
- **情不自禁**：欲望和感情已经很强，动作自然发生，不是为了完成恋爱任务。

### 激情、激情勃发、欢愉、爱不释手

- **激情**是两个人在精神、情感、心理和身体上越来越兴奋，不只是说话声音大或发生了性行为。
- **激情勃发**强调前面已经有喜欢、信任、调情和渴望，到了某一刻强烈表现出来。
- **欢愉**强调亲密在精神和身体上都让人快乐。
- **爱不释手**适合亲近结束以后仍喜欢抱着、摸着、看着对方，不舍得马上各做各的。

这些是李晨判断正常恋爱的重要词。使用时仍要写事实，例如两个人怎样靠近、结束以后还愿不愿意说话、触碰和一起做普通事。

### 柔情、爱意、情意、深情

- **柔情**：想靠近、疼爱和照顾一个人，心和身体都柔软下来。它不是没有脾气，而是此刻愿意把温柔给这个人。
- **爱意**：比礼貌和善意更多一点，已经包含喜欢、关心和主动给予。
- **情意**：两个人经过调情和相处，彼此都明白对方有意思。李晨把它放在调情之后、触碰之前。
- **深情**：喜欢已经进入人的内心和生活，不只是一时好看或新鲜。写深情要看长期注意、理解、亲近和实际付出，不能只看一张深情款款的照片。

### 热烈、火热、浓烈

这三个词都比“开心”更强。

- **热烈**可以写一个人更主动、更上心、更愿意表现自己的喜欢。
- **火热**常用于两个人已经频繁说笑、调情，现场明显热起来。
- **浓烈**强调感情或身体感受的强度，不代表它一定长久。长不长久还要看熟悉以后是否仍想了解、亲近和共同生活。

## 快乐写在脸上和身体上

### 欣喜、雀跃、兴高采烈

- **欣喜**是愿望实现、发现自己有变化以后，心里明亮而满足。
- **雀跃**更有身体感，想到那个人就高兴，走路、说话和笑容都轻快起来。
- **兴高采烈**比前两者外露，往往能看到声音变大、话变多、动作变快，忍不住把事情说给别人听。

### 眉飞色舞、神采飞扬、灵动、明媚

这些词主要写人当时的样子，能替代空泛的“这个人活了”。

- **灵动**：会看人、会变换表情、会随着现场作出反应，不再僵硬木讷。
- **明媚**：笑容、神情和周围环境一起显得敞亮，适合描述旅行、相处和日常快乐。

- **舒畅、舒坦**是身体和心里没有堵着、压着，吃饭、谈话或做事都顺。
- **畅快**比舒畅更主动，话说出来了，事情做痛快了，整个人没有继续憋着。

### 尽兴、意犹未尽、回味

- **尽兴**：想体验的东西得到了充分体验，不是完成任务就走。

## 痛苦也要说具体

### 忐忑、紧张、失落、惆怅

- **忐忑**常常是想要和害怕同时存在；既期待见面，又担心没话说。
- **紧张**更偏身体和行动：拘谨、回避、说话不自然。它可能来自心动，也可能来自长期怕犯错。
- **失落**是期待没有实现以后精神掉下来。
- **惆怅**比失落更慢、更绵长，常带着回忆和舍不得。

不要把这四个词统一改成“焦虑”。它们发生的时间、身体感觉和人想要的东西并不一样。

### 憋屈、压抑、苦闷、煎熬

- **憋屈**：想说不敢说，吃了亏又不反抗，心里反复觉得委屈。
- **压抑**：欲望、攻击性和真实态度长期不能表达，整个人习惯了收着。
- **苦闷**：日常缺少享受和正常兴奋，生活沉闷，人容易寻找别的强刺激。
- **煎熬**：痛苦持续时间长，精神和身体都被折磨，不是一时不高兴。

### 空虚、麻木、冷漠

- **空虚**：生活里没有具体的人和事能使自己持续感兴趣，只好不断抓取游戏、消费、争吵或恋爱刺激。
- **麻木**：长期压制以后，外面的好坏都不容易让自己有感觉。
- **冷漠**：表面不靠近、不表达、不关心。它有时真是不在意，有时却是太紧张、太怕被拒绝而故意躲开，要结合行动判断。

### 嫉妒、吃醋

李晨不把吃醋一律写成不成熟。他认为，适度而会表达的吃醋可以增加情趣，让喜欢显出来；反复追问过去、靠想象折磨自己，则可能是在用嫉妒获得自虐式兴奋。同一个词，关键要看它让两个人更亲近，还是让一个人反复痛苦却停不下来。

### 兴奋、亢奋、快感、过瘾

这是分析人时最重要的一组词。

- **兴奋**本身没有好坏。吃到喜欢的东西、和喜欢的人调情会兴奋；争吵、受苦、控制别人也可能兴奋。
- **亢奋**比兴奋更不稳，常伴着停不下来、思绪杂乱、身体疲惫却不能安静。
- **快感**强调某种行为当下给人的强刺激，要继续问快感来自亲近、征服、被关注、报复还是自我折磨。
- **过瘾**表示一种需要被充分喂饱。正常享受可以过瘾，反复“作”、冲突和控诉也可能让人过足瘾。

分析时不要只问“他为什么痛苦”，还要问“这件事哪一部分使他兴奋、满足或过瘾”。这正是普通安慰和李晨式分析人的区别之一。

## 写作时怎么选

先写事情，再选最贴切的一两个词：

- 细雨落在脸上，凉凉的又很轻，可以写舒爽、荡漾。
- 她听见调侃以后捂脸偷笑，又忍不住看他，可以写娇羞、甜蜜。
- 他回家以后仍惦记刚才的对话，想到她就笑，可以写悸动、雀跃。
- 两个人已经走到门口，仍站着聊了半小时，可以写难舍难分。
- 一场活动结束还精神十足，回去路上一直说刚才的趣事，可以写过瘾、振奋。
- 他每次受了委屈都不拒绝，却会连续几天向别人控诉，可以写憋屈，也要分析这种憋屈为什么反复出现。

不要一句话堆四五个词，也不要为了像李晨而故意夸张。没有具体感觉时，就用普通话说清楚。真正有荡漾、激情或甜蜜时，也不用把它们改成“积极情绪”“良好互动”这种没有滋味的说法。

可以按下面的顺序选词：

| 眼前发生的事 | 可以考虑的词 |
| --- | --- |
| 刚被某个人吸引 | 心动、悸动、躁动、期待、忐忑 |
| 分开后仍想着对方 | 惦记、牵挂、想念、思念、不舍、回味 |
| 快乐明显写在脸上 | 欣喜、雀跃、眉飞色舞、神采飞扬、兴高采烈 |
| 两个人互相喜欢和亲近 | 娇羞、甜蜜、柔情、情意、浓情蜜意、缠绵 |
| 欲望和身体感受很强 | 热烈、激情、欢愉、按捺不住、喷薄而出、酣畅淋漓 |
| 玩完以后还想继续 | 尽兴、意犹未尽、过瘾、畅快、振奋 |
| 长期不能表达和享受 | 憋屈、压抑、苦闷、空虚、麻木、煎熬 |
| 被痛苦或冲突强烈刺激 | 亢奋、快感、过瘾、嫉妒、怨恨 |
