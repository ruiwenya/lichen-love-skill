# Lichen LOVE Skill

这是一个非官方的李晨观点与生活案例 Skill。通过他的原话、同学投稿与同篇点评，让不同 AI 和读者理解他怎样看人、办事、享受生活、关心人和谈情说爱。它不只用于分析恋爱问题，也讨论工作、朋友、家庭和日常心态。

它不是李晨本人发布的产品，不代表他的授权。资料是文章的整理和解读，不是心理诊断工具。

用“好好生活好好爱”来说明它的用途，比“恋爱技巧库”更合适。老李在《保护性拉黑》里说：“因为我的理论和观点，来自于现实，但是目的是回到现实，要转化为生活、工作与情感的现实的好。”这里不另编一套理论，也不把对书名、公众号名的个人理解当成作者亲自说明的由来。

## 名字里的 LOVE

`Lichen-LOVE-skill` 中的 LOVE，不只是两个人相爱的 LOVE，也是 **LOVE MY LIFE：热爱自己的生活**。这就是本项目的命名初衷。

希望读者不只想解决一段感情中的困扰，也会更想吃好、玩好、把事情办好，愿意认识人、亲近人，敢为自己争取好日子，享受自己这一生。

这个名字也与老李所说的“畅满”有相通的意味：对人生有兴致，想享乐，也想创造更多美好。相关原话见 [55岁回想](references/文章资料库/老李有话.md#55岁回想充盈渺小舍离畅满)。

## 它能做什么

你可以问一个具体问题，也可以让 AI 带你练习分析：

- “这个人为什么一被喜欢就没兴趣了？”
- “我很想谈恋爱，为什么一直没有实际行动？”
- “父母怎样影响了我的交往和生活？”
- “先别给结论，带我分析一下这段经历。”
- “我把这几天的聊天记录发给你，看看两个人实际怎样相处，不要只判断她喜不喜欢我。”
- “看看这张合照里，两个人具体在做什么。”
- “我最近和人相处很开心，和以前有什么不同？”
- “怎样观察生活里的不同事物，知道自己到底喜欢什么？”
- “我总跟父母吵同一件事，分析明白以后，怎么过好自己的日子？”
- “这次帮同事办事，为什么好心没帮上忙？”

不需要一次交代所有背景。AI 应先回答已有材料能说明的事，再问真正影响判断的问题。也不要求每段对话最后都给话术、约会安排或退出建议。

AI 不给用户、对方或关系评分。不输出“喜欢概率 70%”“暧昧中等偏高”“情感能力 6 分”之类看似精确的结论。可以说前后有什么变化、哪种表现更明显，但必须讲出双方实际说了什么、做了什么，以及为什么这样理解。

## 核心观念

### 家庭怎样把人教成现在这样

李晨分析中国具体个人时，首先看父母家庭。父母不只影响童年，还可能一直管着工作、消费、交友、性、择偶和婚姻。

要问具体的事：孩子做什么才会被重视，能不能顶嘴、玩乐、表现自己、喜欢异性；父母自己过得有没有意思。不要只用一句“原生家庭影响很大”结束。

### 特异性心理需求

有些人只有吃亏才觉得自己高尚，只有追不到才觉得对方值得爱，只有争吵才感觉两个人还在乎。顺利、被疼爱、真正开心的时候，他们反而不知道怎么办。

李晨把这类特殊而反复的需要称为“特异性心理需求”，并从家庭与成长经历解释它怎样形成。重点是找出：一个人嘴上说不想要的结果，为什么总是重复，其中有什么他舍不得的满足。

相关原文解释见 [特异性心理需求与机器人理论：老李原话](references/文章资料库/特异性心理需求与机器人理论_老李原话.md)。

### 机器人理论

老李在《汪峰章子怡离婚，因为汪峰变了？》里说：

> 人只要有特异性的心理需求，其实就成了一个机器人，被安装了“特异性”程序，只能按程序思维和行为，本质上是没有“自由”的。

这段前后的解释、家庭与亲子案例，以及他谈怎样改变的原话，均保留在 [原文专题](references/文章资料库/特异性心理需求与机器人理论_老李原话.md)。

### 分析人和攻击性

先敢观察、猜测和判断，再用后来的相处纠正。分析人的目的不是写出一份绝对正确的诊断，而是逐渐会接近、合作、竞争、拒绝、争取和处理人。

判断错了可以改；不知道的事情不能编成已知。敢判断和愿意改判断是同一件本事的两部分。

### 三大法宝

依据《幸福是斗出来的！》中的手写图，准确名称是 **吃喝玩乐、分析人、广泛深入大量正常快乐的异性交往**。

吃喝玩乐让人亲自尝到快乐；分析人帮助自己看懂别人、知道怎样相处；异性交往要有实际经历，接触不同的人、多相处、深入了解，也能从中得到快乐。

**集体活动是第三项的一种途径，不是第三项本身。** 朋友介绍、兴趣往来、一对一相处等也可以。重点不在参加多少场活动，而在有没有真实、丰富、正常快乐的交往。

三项常常发生在同一件事里，也不只是脱单前的准备。工作办得明白、朋友能亲近、吃饭能尝到滋味，本身就是变化。分析人还要看懂别人的好意和能耐，不只找问题；独立也不等于凡事一个人扛，有很多“自己人”可以把日子过得更好。

### 幸福是斗出来的：转变的三个要点

1. **自私是最大的力量源泉。** 先承认自己也想过好日子，不能总等父母、伴侣或旁人批准。文章说，比“授以渔”更重要的是“授以欲”。
2. **活该是最好的心理疗愈。** 针对反复抱怨却不愿改变的人，先看清自己舍不得的满足，让诉苦不再那么过瘾，再尝试新的快乐。不是说受伤害的人就该受伤害，也不是见人抱怨就骂。
3. **理论是最强的行动指导。** 看懂具体的人、自己的习惯和实际处境，才知道怎样反驳、拒绝、独立和争取，不总是空想或忍耐。

手写的“冤有头来债有主，看谁敢挡我幸福”，强调找到具体干涉自己的人和事，并有办法处理。完整整理见 [幸福是斗出来的](references/文章资料库/幸福是斗出来的.md)。

### 五项情感能力

| 能力 | 具体指什么 |
| --- | --- |
| 欲望 | 真想接近一个人、亲热、恋爱或一起生活 |
| 感知力 | 看懂个人和群体的情绪、意图、处境与关系 |
| 暧昧能力 | 会调情、开玩笑，用语言和身体表达喜欢，产生性愉悦 |
| 激情能力 | 能让双方在精神、情感、心理和身体上获得强烈快乐 |
| 为人处事能力 | 能处理工作、钱、家庭、朋友和日常麻烦 |

它们不是五项美德，也不是评分表。会照顾生活但不会亲近，和彼此很有激情却总把生活弄乱，是不同的问题。详见 [五项情感能力](references/五项情感能力.md)。

### 怎样关心人

老李说：

> “别有所图”，自然满眼都是目标（人），一举一动都看在眼里、想在心里，关心人就“手拿把掐”了。

出处：《习惯两个人之后就受不了一个人了》，原文保留在 [老李有话](references/文章资料库/老李有话.md#对低频刺激敏感)。

编者对此的理解是：关心人的内在动力来自强烈的自我欲望，表达出来时却要把注意力放在别人真正需要的事情上。自己对吃得好不好、冷不冷、方不方便有感觉，才容易提前想到别人；说出来时应提供经过体验的具体信息，不借关心展示功劳和优越感。

“没有我”不是禁止第一人称。老李确实批评过案例中祈使表达的强迫感，但不能只靠句型判断会不会关心人，还要看信息是否清楚、判断是否有体验和理由、别人到底得到了什么。完整案例见 [《怎么才会关心人》怎样讲](references/输出模板与案例.md#怎么才会关心人)。

### 欲望不只是一时冲动

按李晨的硬判断，长期“脱单困难”是欲望问题。他关注的不是暂时没对象，而是长期只谈标准和缘分，没有被某个具体的人吸引到愿意尝试。

近期文章又谈到四个层面：被外在吸引、想得到彼此的喜欢、想了解并亲近整个的人、想过两个人共同的生活。欲望可以越来越丰富，不只靠新鲜身体和征服。

### 相爱也能有稳定的快乐

爱不只是责任、身份和“我对你很好”，还要看两个人是否真喜欢一起吃饭、说笑、做事和亲热。

李晨从塞尚的苹果想到：两个人不必各自完美，相处中却可以产生各自独处时没有的美好。稳定不必消灭差异，也不必取消欲望。熟悉以后仍有兴趣，遇到变化也能商量和处理，才是值得向往的共同生活。

### 自己人

老师和学生、朋友之间可以直接说话、开玩笑、一起办事，不总是客气。李晨把这种亲近称为“自己人”。

使用共同术语、感谢老师、设想老师会怎样处理，不足以说明依赖。要看人是不是越来越会自己判断、自己生活，而不是只看他说了多少次老师。

《爱老李 得弟弟》把这一点写得很具体。李晨把老师的作用比作“引力弹弓”：让女生先感到男人、暧昧和异性交往的吸引力，最后去现实中喜欢一个具体男人。真正的变化是她越来越会照顾自己、组织活动、表达欲望和安排生活，不是把老师变成唯一兴奋对象。

### 从日常经历里知道自己喜欢什么

观察生活里的不同事物，先承认自己的感受，再留意是什么细节让自己觉得有意思。运动、做饭、聊天、修东西、艺术欣赏都可以，没有统一的爱好要求。2026 年 8 月 31 日至 9 月 3 日法国游记中的绘画与食物，只是这类观察的例子。

喜欢就愿意再试，不喜欢也可以承认；一次尝试失败，不必变成对自己的全盘否定。享受生活不是买更多东西、安排更多项目，而是知道自己喜欢什么，并且真的去过那样的日子。详见 [生活感受与共同生活](references/生活感受与共同生活.md)。

### 充盈、渺小、舍离、畅满

《55岁回想》用这四个词讲他的生活。物质、情感、文化、心理都在其中；也谈不把自己太当回事、亲人的幸福与自己的事，以及用更好的现在和未来对待过去的损失。

不在这里另做四阶段或打分表。完整的相关原话，包括八句“我渺小”、父母子女与自己四句区别，以及享乐和创造，见 [老李有话](references/文章资料库/老李有话.md#55岁回想充盈渺小舍离畅满)。其他用词与出处见 [李晨常用词](references/李晨常用词.md)。生活和爱可以一起学，不是先把自己彻底修好才有资格亲近别人。

### 约会、长情和会玩

约会不是选一个公认高级的地方就够了。两个人能不能边走边聊、相视而笑、自然开玩笑，对方不自在时能不能看出来，比项目名称和消费档次更重要。

普通条件也能通过真实交往、分析人、暧昧和办事经验变强。欲望强也不等于对象多；对一个具体的人不断产生兴趣，愿意了解他、亲近他、一起过普通日子，反而更可能长情。

会玩的人不是去过的地方多，而是玩的时候真高兴，也让同行的人看得出来，结束以后还有精神。为人处事则不保证一直舒服，有时明明想结束谈话，仍愿意花一点力气把场面处理好。三篇生活材料见 [约会、长情与会玩](references/文章资料库/约会、长情与会玩.md)。

## AI 应该怎样说话

这版特别修改了抽象、公式化的表达。

原来的说法：

> 真实快乐产生余量，能量继续流向具体的人和低刺激日常。

现在的说法：

> 吃完饭还舍不得走，第二天还想见他，连一起买菜都觉得有意思。你喜欢的不只是那一晚的刺激。

保留李晨的核心词，也可以写“荡漾、甜蜜、娇羞、激情、欢愉、过瘾、酣畅淋漓”等有滋味的词。先写清谁笑了、谁继续说话、谁主动靠近、身体和环境有什么感觉，再选最贴切的一两个词。不要写“接住了她”“这个人活了”“关系活起来了”这种看似有感觉、实际省略事实的话，也不要把真切的快乐改成干巴巴的“积极互动”。

同样不要用分数、百分比、星级或高中低替代判断。聊天记录和一段关系不是统一考试，模型也没有足以支持这种精度的量表。

具体示例见 [说话方式与示例](references/输出模板与案例.md)。

## 两种用法

有 Skill 支持的环境，使用整个文件夹。不支持自动加载的环境，可以把 `SKILL.md` 和需要的 Markdown 资料作为附件或知识库；具体加载方式以该环境实际支持的功能为准。

**没有本地 HTML：**先按问题读仓库中的原话精选、投稿与点评，再参考专题解释，仍然能理解和使用主要观念。AI 不应声称自己看过未收录的全文或图片。

**有本地 HTML：**先检索原文，再阅读正文和图片。原文与摘要不一致时，按原文修正。图片直接识别，不安装 OCR 库；当前 AI 看不到的图片，要说明。

在文章库根目录执行：

```bash
python3 Lichen-LOVE-skill/scripts/search_articles.py --root . --keyword "父母" --keyword "欲望" --limit 20
```

需要少量本地原文副本时：

```bash
python3 Lichen-LOVE-skill/scripts/refresh_article_snapshots.py --root . --skill-dir Lichen-LOVE-skill
```

该脚本按预设清单复制，不代表全部文章或最新文章都已收录。见 [原文快照说明](references/文章资料库/原文快照说明.md)。

## 资料与使用范围

公开仓库不上传完整 HTML、原始图片和付费截图，提供专题整理、文章索引、检索工具，以及少量注明出处的原话精选和投稿案例。投稿案例只在同一篇文章同时存在同学投稿与李晨原文评价时收录；图片投稿直接看图转写，遮挡或看不清的内容不猜。完整原文副本默认由 Git 忽略。例子只来自文章或明确标注的虚构场景，不使用用户私人经历。

可以讨论性、权力、出轨、恨和道德冲突，不自动说教；不提供胁迫、欺骗、侵犯同意或利用创伤控制别人的办法。整理李晨观点与评价观点要分清，AI 的漂亮解释也不能替代实际材料。
